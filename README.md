# Hospitality Revenue Analytics

## 📊 Project Overview

An end-to-end hospitality revenue analytics project focused on analyzing hotel booking data to identify revenue trends, customer behaviour, booking patterns, cancellation trends, and business performance.

The project follows a complete analytics workflow using **Python, MySQL, and Tableau**, transforming raw booking data into actionable business insights.

---

## 🎯 Business Problem

Hotels generate large amounts of booking and customer data, but raw data alone does not provide clear insights for business decision-making.

This project analyzes hotel booking data to answer key business questions such as:

- How is overall revenue performing?
- Which hotel type generates more revenue?
- Which customer segments contribute the most revenue?
- Which booking platforms generate the highest booking volume?
- How does lead time relate to cancellation behaviour?
- How do repeat and new guests differ in cancellation rates?
- How does discounting relate to final revenue?
- Which stay durations contribute significantly to revenue?
